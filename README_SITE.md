# Voyage Doré — Lokale Vorschau

Kurzanleitung, um die Website lokal anzusehen:

1. Terminal öffnen im Workspace-Root.
2. Einen einfachen HTTP-Server starten (Python 3):

```bash
python3 -m http.server 8000
```

3. Im Browser öffnen: http://localhost:8000

Die wichtigsten Dateien:
- `index.html` — Startseite
- `about.html` — Philosophie
- `destinations.html` — Ausgewählte Orte
- `gallery.html` — Bilder
- `contact.html` — Kontaktformular
- `css/styles.css` — Stylesheet

Wenn du Änderungen möchtest (Farben, Typo, Bilder), sag mir kurz, was du bevorzugst.
